
# SLOT-GAME

## Опис проєкту

SLOT-GAME — це навчальний Java-проєкт, який реалізує симуляцію роботи слот-машини «Однорукий бандит».

Програма дозволяє користувачу грати в слот-гру, робити ставки, отримувати виграші та переглядати результати обертань.

Також передбачена можливість математичного аналізу роботи слот-машини за допомогою симуляції великої кількості обертань та розрахунку основних статистичних показників.

## Основні можливості

- Імітація роботи трьох барабанів слот-машини.
- Генерація випадкових комбінацій символів.
- Встановлення ставок та управління балансом гравця.
- Визначення виграшних комбінацій.
- Розрахунок сум виграшів.
- Симуляція великої кількості обертань.
- Розрахунок імовірностей виграшних комбінацій.
- Аналіз основних показників роботи слот-гри.
- Відображення результатів та статистики в консолі.

## Запуск програми

1. Клонувати репозиторій.
2. Відкрити проєкт в IntelliJ IDEA.
3. Переконатися, що встановлено JDK 17 або новішу сумісну версію.
4. Дочекатися завантаження Maven-залежностей.
5. Запустити клас Main.java.
